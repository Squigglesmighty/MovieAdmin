# Movie Database Administration Web App

Admin side of movie database web app.

## Overview

I am currently learning how to build this app as a school project using C# and the ASP.net framework.
This is the admin section of that app. It's essentially a recreation of rottomtomatoes.com where you can search and filter movies by
genre, release date, rating etc....

## Current Progress
This is a work in progress. Currently only the base structure of the webpage has been created.

## Tech Stack

- **Language:** C#
- **Framework:** ASP.NET Core
- **IDE:** Visual Studio

## Prerequisites

- Visual Studio (2022 or later)
- .NET 6.0 or later
